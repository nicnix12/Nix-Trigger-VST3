# Nix-Trigger-VST3
Nix Trigger: Dirancang fokus, efisien, dan straightforward. Memuat 1 file one-shot drum (WAV/FLAC/AIFF) dengan polifoni 8 suara (fast roll tidak akan terpotong), atau difungsikan sebagai jembatan audio-to-MIDI murni untuk mentrigger plugin drum berukuran besar seperti Superior Drummer 3, EZdrummer, Addictive Drums, atau Steven Slate Drums.
